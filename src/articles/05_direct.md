# Insurance Frontend & CMS Development

Direct is a Czech insurance company. Frontend modernization and CMS development, combining modular applications, shared packages, and integrated authentication flows.

## Overview

My work focused on modernizing its frontend architecture and developing CMS functionality. The technology stack included Next.js, Node.js, Vite, and Redis, with Keycloak supporting authentication flows.

The architecture used micro-frontends and shared packages to organize application functionality and reusable code. This approach supported maintainability and continued development across frontend applications.

My responsibilities included technology selection, architectural decision-making, and code reviews. I contributed to code quality and quality assurance, helping evaluate implementation choices and verify that delivered functionality met project requirements. The work combined hands-on development with a focus on consistent engineering standards and maintainable application design.
