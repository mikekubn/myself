# Point-of-Sale Platform

A point-of-sale ecosystem combining a modular web application, backend services, and centralized authentication and authorization.

## Overview

Papaya POS combines a Nuxt and Vue web application with Kotlin backend services. Keycloak supports authentication and authorization, Apache APISIX serves as the API gateway, and Redis forms part of the backend infrastructure. Helm charts support deployment configuration.

The platform emphasizes modular application design, reusable components, and integration between frontend applications and backend services to support maintainability and continued product development.
