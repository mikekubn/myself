# IP/TV Frontend & Quality Assurance

Frontend development and quality assurance for Livesport’s IP/TV project, combining React application development, CMS functionality, mailing services, and automated testing.

## Overview

I contributed to the development of Livesport’s IP/TV project as part of the frontend and quality assurance team. My work combined frontend implementation with testing to support application quality and continued development.

The project used React for frontend development, Playwright for automated testing, and a CMS for content management. Fastify was used to develop mailing services, while Docker supported containerization within the development workflow.

My responsibilities included developing frontend functionality and mailing services with Fastify, as well as contributing to quality assurance, helping verify application behavior and identify issues throughout development.
