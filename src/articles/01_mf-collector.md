# Industrial IoT & Data Collection Platform

An on-premise solution for collecting, processing, and synchronizing manufacturing data, with web and mobile applications, backend services, secure access, and AI analytics.

## Overview

MF Collector connects manufacturing data collection with backend processing and analytics in an on-premise environment. The solution combines a Next.js web application, an Expo (React Native) mobile application targeting Android and iOS, and NestJS backend services.

Its technology stack includes Prisma and SQL databases for data access, LangChain for AI functionality, Keycloak for authentication and authorization, Redis, and Apache APISIX as the API gateway. Docker and GitHub Actions support containerization and CI/CD.

My responsibilities included technical ownership and decision-making, guiding architectural choices and implementation priorities across the platform. I evaluated trade-offs between business requirements, maintainability, and integration needs to inform the technical direction.
