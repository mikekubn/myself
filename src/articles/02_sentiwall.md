# Enterprise Security & AI SaaS Platform

A SaaS platform combining enterprise security and AI-powered capabilities through a web application, backend services, and centralized identity management.

## Overview

Sentiwall is an enterprise-oriented SaaS platform with a Next.js web application and Python backend services. Its technology stack combines SQLAlchemy and SQL databases for data access, LangChain for AI functionality, Keycloak for authentication and authorization, Redis, and Apache APISIX as the API gateway. Docker and GitHub Actions support containerization and CI/CD.

The architecture focuses on security, scalability, and tenant isolation, with clear responsibilities across business logic, AI processing, and infrastructure.
